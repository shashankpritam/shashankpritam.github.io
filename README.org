#+TITLE: shashankpritam.github.io

Personal website for [[https://shashankpritam.github.io][Shashank Pritam]].

Built with Emacs [[https://orgmode.org/manual/Publishing.html][org-publish]].

* Structure

#+BEGIN_EXAMPLE
org/           ← source pages (.org)
static/
  css/         ← Stylesheet
  pics/        ← images
publish.el     ← org-publish build script
public/        ← generated HTML
#+END_EXAMPLE

* Build locally

Requires Emacs (29+).

#+BEGIN_SRC sh
emacs --batch --load publish.el
# output in public/
#+END_SRC

Open =public/index.html= in a browser to preview.

* Deploy

Pushing to =main= triggers the GitHub Actions workflow (=.github/workflows/pages.yml=), which installs =emacs-nox= and runs =publish.el=. Output is deployed to GitHub Pages automatically.

* Theme

A small hand-written stylesheet (=static/css/style.css=) in the style of an early-2000s university homepage: a green top bar, a gray sidebar, one column of text, and a row of 88x31 badges in the footer. All text is set in Geist Mono.

=publish.el= builds the chrome. =sp/pages= lists the pages for the sidebar and =sp/elsewhere= the profile links; each is defined once. On the current page the sidebar also lists that page's top-level headings, read from any heading with a =CUSTOM_ID=, so renaming a heading renames its sidebar link.

There is no dark mode, so the page looks the same whatever the reader's OS theme.

* No JavaScript

The site has no =<script>= elements at all. Navigation and pictures are plain HTML and CSS rendered at build time.

A =Content-Security-Policy= meta tag enforces this: =script-src 'none'=, everything same-origin, with Google Fonts the sole third-party origin allowed for styles and fonts.
