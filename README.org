#+TITLE: shashankpritam.github.io

Personal website for [[https://shashankpritam.github.io][Shashank Pritam]].

Built with [[https://typst.app][Typst]]'s HTML bundle export, on this machine; GitHub Pages serves =docs/= from =main=.

* Structure

#+BEGIN_EXAMPLE
site.typ       ← the bundle: includes every page, ships static/ as assets
chrome.typ     ← head, header, page bar, footer, shared by all pages
pages/         ← one .typ per page
static/        ← stylesheet, favicon, pictures, CNAME (shashankpritam.com)
site.sh        ← build, or serve with live reload
docs/          ← generated site (tracked; this is what Pages serves)
#+END_EXAMPLE

* Build and publish

Requires Typst 0.15 (HTML and bundle export are still marked experimental there).

#+BEGIN_SRC sh
./site.sh serve   # build into docs/, serve at http://127.0.0.1:3000, rebuild on save
./site.sh         # build into docs/
#+END_SRC

To publish, build, commit =docs/= with the source, and push =main=. GitHub Pages serves =main:/docs= as is (=.nojekyll=, no Actions workflow).

* Layout

The common academic homepage, with standard parts: a skip link, then the name and a row of page links in the header, then a profile column (role, lab, every outside link) beside the text. No footer; the profile already holds those links. On a phone the profile moves above the text. Links are underlined, the current page is marked in code and in weight, focus shows a thick ring, and the body is 17px Geist.

=chrome.typ= builds the chrome. =pages= lists the pages for the header and =elsewhere= the profile links; each is defined once. A page that passes =toc= gets an "On this page" list in the profile column (the notebook does).

** Colour

The tokens between the marker comments at the top of =static/css/style.css= are written by the house-style =paint= script; edit the tokens there, not here. The header switch swaps between Rex day and its dark twin (see below).

* No JavaScript

The site runs no script; the =Content-Security-Policy= meta tag says so (=script-src 'none'=), with Google Fonts the sole third-party origin for styles and fonts.

The round switch in the header is a checkbox and its label. The page follows the device's light or dark mode, Rex day for light; ticking the switch swaps to the other theme through =:has(#flip:checked)= in the stylesheet. With no script there is nowhere to keep the choice, so each page opens on the device's mode again.
